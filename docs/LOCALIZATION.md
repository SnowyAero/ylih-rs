# Guía de Traducción e Idiomas (`.pak`)

YLIH-RS utiliza archivos `.pak` ligeros en formato `clave = valor` ubicados en la carpeta `locales/`.

## Cómo añadir o personalizar un idioma
1. Copia `locales/es.pak` o `locales/en.pak`.
2. Para probar cambios en vivo sin recompilar, coloca tu archivo en:
   `~/.local/share/ylih/locales/es.pak` (o `en.pak`).
3. Las líneas que comienzan con `#` son comentarios y se ignoran.
